## Монитор (`tools-core/monitor`)

- [x] **In-memory история.** `TaskHistory` (кольцевой буфер глубины `deep_history`),
  запись в `TaskEntity::update_snapshot`, read-model `HistoryEntryView` и доставка в
  `TaskView` через broadcast.
- [ ] **History-sink (персистентность истории).** `LogWriter` trait (`dyn`) + writer-актор
  + `mpsc` (файл / sqlite). Память переживает рестарт. — ARCHITECTURE O-6.
- [ ] **Лимит рестартов + статус `Failed`.** Сейчас backoff бесконечный (cap 60s); нужен
  `max_restarts` и терминальный статус для детерминированно падающей задачи. — O-2.
- [ ] **Второй use-case** (`http-read` или `icmp-ping`) — проверить рецепт §10.
- [ ] **`snmp-set`** — отдельный командный путь (не периодический опрос).
- [ ] **Web-интерфейс** поверх `OrchestratorHandle` (`subscribe` уже есть).
- [?] **Автокорреляция между задачами.** Сравнение снапшотов в группе. — O-7.

## SNMP / SCN (`tools-core/snmp`, `tools-core/ascii`)

- [x] **Разделение форм SCN.** `to_scn_index` / `parse_scn_index` (чистый
  `{len}.{codes}`) и `to_utc_index` / `parse_utc_index` (`.1.{len}.{codes}`, где
  `.1` = `utcType2TimeStamp` «now»).
- [ ] **Парсер логов UTC SET.** Извлекать SCN + фазу из OID-индекса и значения битовой
  маски (для разбора логов устройства).
- [ ] **Переименование `Ascii` → `Scn`.** Номенклатура типа (отложено).
- [?] **Расхождение длины SCN в лог-OID.** `…1.6.67.79.57.57.52` — префикс длины `6`
  при 5 байтах (`"CO994"`). Сверить с сырым varbind'ом на устройстве (NUL/пробел в хвосте?).
