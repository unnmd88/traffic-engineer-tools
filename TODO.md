# Оставшаяся работа по контракту монитора

Принятые правила метаданных, событий и расширяемости публичных типов описаны
в [ARCHITECTURE.md](docs/ARCHITECTURE.md#результаты-события-и-snapshot).

## Согласование подписки со snapshot

- [ ] Добавить в `MonitorSnapshot` источник и `next_seq`, получаемые вместе
  с состоянием в оркестраторе.
- [ ] Обеспечить последовательность: подписаться, получить snapshot,
  применять события начиная с его `next_seq`.
- [ ] Обрабатывать `RecvError::Lagged` в CLI: повторно читать snapshot
  и продолжать обработку событий.

## Проверки

- [ ] Выполнить отложенный прогон тестов контракта монитора. Тесты с локальными
  UDP-сокетами пока не запускать; сборку тестов проверять через `--no-run`.
