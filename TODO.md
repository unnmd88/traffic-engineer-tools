# Оставшаяся работа по контракту монитора

Принятые правила метаданных, событий и расширяемости публичных типов описаны
в [ARCHITECTURE.md](docs/ARCHITECTURE.md#результаты-события-и-snapshot).

## Хранение событий

- [ ] Определить гарантии записи истории и поведение при медленном потребителе
  `history_sink`, включая распределение ответственности между библиотекой
  и вызывающим кодом.

## Проверки

- [ ] Выполнить отложенный полный прогон тестов контракта монитора. Тесты
  с локальными UDP-сокетами пока не запускать и новые UDP-тесты не добавлять.
  Проверки подписки без сокетов запускать отдельно, остальные тесты собирать
  через `--no-run`.
